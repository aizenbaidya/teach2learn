# Teach2Learn

[teach2learn.education](https://teach2learn.education/)

## Setup

1. `python3 -m venv .venv`
2. `source .venv/bin/activate`
3. `pip install -r requirements.txt`
4. `npm i`
5. `./dev.sh` or `./run.sh`
6. Voila!!
